# 要件

## アプリ概要

ADHD Stack は、何も考えずに始められる開発と公開。ホストは `adhd.gawarago.com`。

開いたらヒーローの下に、つなぐものが4つ並んでいる。ChatGPT、GitHub、Cloudflare、Convex。接続状態はノード UI で見える。全部つながったら、考えることはもうない。エディタへ進む。

リポジトリも Codex Cloud 環境も、公開先の Pages と Convex も、つながったアカウント側に勝手に用意される。チャットで話すだけ。thinking、いまやってること、コマンド、ファイル差分が出る。IDE は開かない。OAuth は全部本物。

## 画面一覧

### 接続

最初の画面。ヒーローの下に4つのログインが並ぶ。各サービスはノードで、つながるとノードが生きる。全部つながるまでエディタには行けない。切れたノードはそこからつなぎ直す。

### エディタ

4つ全部つながったあとの画面。入った時点で GitHub リポジトリと Codex Cloud 環境がある。チャットが本体。指示を出す、作業中が見える、ファイルが変わる、公開すると URL が返る。

## ユーザーストーリー

- 開いて、4つログインするだけで始めたい。構成やホスティングは考えたくない
- どれがつながってて、どれがまだか、ノードを見て分かりたい
- 全部つながったら、すぐエディタでチャットしたい
- チャットの指示だけでコードが書き換わって、自分の Cloudflare と Convex に出たい
- どれか切れたら、接続の画面でそのノードだけつなぎ直したい
